# Hojalatería Los Cerezos · Sitio Web Oficial

> Taller de hojalatería técnica, corte y plegado de zinc a medida en El Quisco (Algarrobo, El Quisco y El Tabo, Región de Valparaíso, Chile).

## 🛠️ Tecnologías y Características
- **Frontend**: HTML5 Semántico + JavaScript Vanilla
- **Estilos**: Tailwind CSS CDN + CSS Técnico Industrial Blueprint CAD (`assets/css/technical.css`)
- **Simulador Interactivo**: Campana de Quincho a medida en SVG dinámico con vista dual "Plano CAD vs Fabricación Real"
- **SEO Local**: Schema.org JSON-LD (`LocalBusiness` & `HomeAndConstructionBusiness`), Geo-metatags, Open Graph enriquecido para WhatsApp
- **Ciberseguridad**: Content Security Policy (CSP) estricta, mitigación de Reverse Tabnabbing (`rel="noopener noreferrer"`), sanitización de parámetros numéricos
